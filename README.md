## Claude への決まり（このページの直し方）

- 仕組みを足した・変えた・止めた時は、**その作業の最後に**このページの表と「変更の記録」を直して保存する。後回しにしない。
- 表の言葉は、ひろきが読んで分かる言葉にする（ファイル名やプログラム名を主語にしない）。細かい事は各リポジトリに置き、ここはリンクだけ。
- 保存する前に、必ずこのリポジトリの main の最新を読み直す。
- 毎週の定期タスク「全体の地図の見回り」が、各リポジトリの 1 週間の変更とこのページを見比べ、漏れていれば直す。
