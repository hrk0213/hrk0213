# ひろきの仕組みの一覧（全体の地図）

**ここが全部の入口です。** どの仕組みが何をしていて、どこを見ればよいかを 1 ページにまとめています。
仕組みを足したり変えたりしたら、Claude が同じ作業の中でこのページを直し、一番下の「変更の記録」に 1 行書きます。

最終更新：2026-10-10

## 0. ひろきの作業環境（Claude が最初に知っておく事）

- ひろきは**いつも PC の Claude デスクトップアプリ**で Claude と作業している。PC の Chrome（Claude in Chrome）もだいたい開いている（2026-10-08 ひろき）。
- だから「デスクトップアプリで開いてください」「Chrome を開いてください」とひろきに頼まない。
- 店のデータ（種類・値段・状態など）は、**まず公式 API で取る**事を考えてから動く（2026-10-08 ひろき「API まずで思ってからやった方がいい」）。
- このチャットが PC とつながっていないように見える時も、ひろきの環境のせいにして作業を止めない。API とクラウドで出来る所を先に進め、どうしても PC が要る所だけ、何が要るかを具体的に伝える。

## 3. Claude の残量が切れた時（GPT・クラウドセッションのクレジットで続ける）

調べた日：2026-10-09（定期タスクの一覧・チャット自動返信のプログラムを見て確認）

### そのまま動き続ける物（Claude の残量と関係ない）

### 止まる物（claude.ai の定期タスク＝Claude の残量を使う。13 個）

価格改定の判断待ちの通知（毎朝）／チャット返信の毎日の学習／Amazon 本体の発送の戻り確認／Shopee 商品の反応（月曜）／BR 新着（月曜）・BR 売れ筋（毎月 1 日）／JOOM リサーチ（火曜）・未許可ブランド（月曜）・送料表（毎月 2 日）・経営ダッシュボード（5 日・20 日）／全体の地図の見回り／仮想通貨ブリーフ／X ブックマーク確認

→ 残量が戻れば再開する。クラウドセッションのクレジットや GPT では代わりに動かせない。止まって困るのは「判断待ちの通知」と「チャット返信の学習」の 2 つ（返信自体は止まらない）。

### ① クラウドセッションのクレジット（250 ドル・11/5 まで）で続ける場合

- 10/10 に確認：この 250 ドルは API のクレジットではなく **「クラウドセッション」専用**。使っている間はプランの残量を減らさない。普通のチャット・定期タスクには使えない（[公式の説明](https://support.claude.com/en/articles/17152539-cloud-sessions-bonus-credit-promotion)）。
- 使い方：Claude デスクトップアプリの **Code** で、GitHub のリポジトリ（例：shopee-br-claude-listing）を選んで新しいセッションを始める。チャットの形でそのまま話しかけられる。クレジットは自動で使われる。
- クラウドで動くので、PC の中の物（価格改定の道具・切り抜きの窓口・Chrome）には届かない。GitHub と API（Shopee・JOOM・Amazon）で済む作業に向く。

### ② GPT（PC の Codex）で続ける場合

- Codex 用のスキルは消さずに残してある（2026-10-04 決定）。
- PC の Codex で作業するリポジトリを開き、最初にこう言う：
  「まず https://github.com/hrk0213/hrk0213 の README を読んで、次にこのリポジトリの README と docs を読んでから作業して。決まりは ec-knowledge にある」
- 出品・作り直し・価格改定の道具はプログラムなので Codex でも動かせる。ただし **送る前に確認ページを見せる** 流れは claude.ai のページを使っているので、Codex では確認を表かファイルで出してもらう。

### ④ 進行中の作業の振り分け（2026-10-09 時点・GitHub の Issue から）

分け方：**店の値段・出品を変える物と判断が要る物 → クラウドセッション**（GitHub と API で済む物）／**プログラムを直す・PC で長く回す物 → GPT（Codex）**／ブラウザ（Claude in Chrome）や Canva が要る物 → Claude が戻るまで待つ。
